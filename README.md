# MAPA-VALIA

Módulo de mapa real del Vallès Oriental para la app **Valia**.

- [`valia-map/`](valia-map/): módulo listo para integrar (MapLibre + OpenFreeMap + OSM + Terrain Tiles + ICGC). Ver [`valia-map/README.md`](valia-map/README.md).
- [`valia-map.zip`](valia-map.zip): la misma carpeta comprimida, para descargar.
- [`valia-map/PROMPT-INTEGRACION.md`](valia-map/PROMPT-INTEGRACION.md): prompt para integrarlo en la app.
- [`capturas/`](capturas/): capturas de `demo.html` en móvil (412 px) y escritorio.
